## 已知坑（踩过的，别再踩）

- URL 里的 `#` 必须百分号编码（`_media_url`），否则浏览器当锚点截断 → 404
- 小红书裸域 `xiaohongshu.com` 须归一化 `www.`（`_resolve_xhs_download_url`），否则下载器提取失败但退出码 0
- F2 收藏夹 `aweme_list=null` ≠ 夹被删，是夹内容不可读（streak 3 轮收尾）
- 推特 v1.1 verify_credentials 已被 X 下线（404）→ 检测降级 WARN，勿误报未登录
- RSSHub `pnpm install` 用 npmmirror registry；全局装 pnpm 后要软链到 `~/.local/bin`
- 后端测试 527 项；3 个失败（test_mac_lifecycle 1、test_personal_source_loop 1、test_personal_source_schedule 1）是改动前已存在的环境问题，stash 对照确认过
