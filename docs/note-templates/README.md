## 四、使用方式

1. 先判断内容形态（口播/动作教学/跟练/图文），选对应模板。
2. 复制模板正文，替换占位符。
3. 博主原话、动作、数字挂 `[^vN]`；外部支持挂 `[^sN]`；冲突挂 `[^qN]`；查不到挂 `[^uN]`。
4. 文末补「证据台账」和「参考文献」。
5. 按 `v2/00-引用标记规范.md` 第八节做发稿前检查。

## 五、硬规则

- 数字必须来自转写原文或画面，不得把自己的推算写成“他说”。
- 同音错必须列，不能照抄错名。
- 文献不得编造；查不到就写「本条未找到直接研究」。
- 不确定标 `[待核]`。
- 画面实读只写实际看到的，图注不能按口播想象。
- 外部证据约占 20%，不能因为加脚标变成文献综述。
- 支持与质疑都要列，只列支持视为不合格。
