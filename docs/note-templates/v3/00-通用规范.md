# 健身训练笔记 v3 通用规范

适用于健身训练、动作教学、运动科学、恢复、训练计划与运动营养。保留博主的原意、推理、示例、训练条件和关键数字。作者自述、实读画面、整理者推断和外部研究分别标注。冲突并列展示，跨作品关联只能补充各自的笔记。

- 保留原始转录和 OCR，纠错另列原值、修正、定位和依据。模糊文字用「待核」。
- 视频画面单独核对。真帧只能证明所摄瞬间，路径或全程需要多帧或片段。剪掉休息不代表零休息，示范一组不代表计划只有一组。
- 数字保留单位、条件和出处。未说明写明原因，JSON 数值或训练参数用 null。可计算总量单列算法和分母，不替换作者给出的值。
- 正文以原片为先，外部篇幅随主张重要性与风险变化。无需固定比例或凑质疑。
- Markdown 是阅读版，JSON 是同一笔记的机器版。时间统一为相对片头的整数毫秒，图文保留原帖图片顺序。引用脚标与 JSON evidence 的 ID 一致。
- 程序填写可知素材身份、版本、生成时间和指纹。未知发布时间和片长保留 null。分别报告实际转录、画面、外部核验与审阅状态。
- 现有下载、转录、OCR、帧或研究缓存仍可复用。处理深度改变不触发重下或重做素材。仅在输入实际变化时刷新，并保存前次可用结果。
