# 80/20 笔记模板 · 口播/理论类（v3）

> 适用：口播、白板讲解、理论拆解、经验总结等以「说」为主、画面信息量低的视频。
> v3 新增：① 文件头 YAML frontmatter，归档与筛选可直接读结构；②「来源与素材摘要」一次交代转写段数/字数/口播密度、实读帧数与证据分布；③ 主体固定为「概念定义 → 机制链 → 分节要点 → 反例与边界条件」，机制句逐句挂脚标；④ 证据台账增加 DOI/URL 列；⑤ 文末 100 分制「质量自评」，80 分通过。
> 脚标规范：`../v2/00-引用标记规范.md`。v3 沿用 v2 的五类脚标，不新增类型。
> 编号说明：下文的 `[^vN]`/`[^sN]`/`[^qN]`/`[^dN]`/`[^uN]` 全是占位。复制后按正文实际出现顺序重新编号，同一来源复用同一编号，并在文末补齐定义。
> 比例硬约束：原片与博主内容约 80%，外部证据约 20%；外部内容集中在「外部对照」一节，正文不做成段文献综述。
> 使用顺序：先复制下面的 YAML 块放到笔记首行，再复制正文块；两块的证据条数与质量总分必须一致。
> 本类常见扣分点：机制链混入笔记作者的补写；反例被并进主结论；板书节写了画面看不到的内容；定义与机制链各说各的。
