# 分类与处理深度

| 内容主要价值 | 主模板 |
|---|---|
| 解释为什么及如何应用，含口播、白板、原理或经验 | [口播理论](templates/01-口播理论类.md) |
| 教观众做一个动作或一组相关变式 | [动作教学](templates/02-动作教学类.md) |
| 按顺序带观众完成训练课程 | [跟练](templates/03-跟练类.md) |
| 核心信息来自静态图片、配文或收藏清单 | [图文收藏](templates/04-图文收藏类.md) |

从素材内容和目的选择一个主体，同时保留其他形态的关键段落。素材不足时写待核。单动作反复示范不等于跟练，无转录也不等于图文。按内容启用[训练计划](modules/训练计划.md)或[运动营养](modules/运动营养.md)，两者可并存。素材不属健身范围时退出并说明原因。

- quick 保留核心观点、原片位置、所有重要训练数字与实际顺序。缩短解释，按需读帧。
- standard 完整保留教学步骤、纠错、关键帧、训练速查及必要的外部核对。
- deep 增加动态或对照画面、多来源研究与跨作品的支持、补充或冲突记录。关系须指向实际已有 ID。
- 三档均按主张风险独立选择 V0/V1/V2。核验受限时留下状态，正文呈现可确认内容。
