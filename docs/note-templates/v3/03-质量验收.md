# 真实素材验收

固定验收清单：2 条口播理论、2 条动作教学、2 条跟练、2 条健身图文，另选训练计划混合内容和运动营养或科学争议内容各 1 条。优先挑已有来源 ID、转录与帧的作品。用原片与原帖做参考，v2 既有演示只能作对照，软件工具收藏不纳入健身图文。

1. 每条登记素材 ID、输入可用性、v2 笔记版本、v3 深度和核验等级。用隔离输出目录跑同一输入。记录用到的素材文件和哈希。
2. 对照人工清单逐项检查原话、重要观点、动作顺序、关键数字、确切单位、时间/图号、实际看到的画面与图片链接。区分遗漏、错误和待核。看不清或缺视频时明确验收范围。
3. 打开每条外部引用，核对身份、对应结论和边界。没有外部运行记录时不算已核验。检查 JSON Schema、引用映射、素材定位、Markdown 可读性和可追溯的实操清单。
4. 加测同音误识、缺帧、未说明参数、前后矛盾、检索失败、深度升级和相同输入重跑。保留原始转录，对照重跑是否产生第二份同深度笔记，核对下载/转录/OCR/抽帧是否重复调用。
5. 按同一口径记录保留项/总项、错误、遗漏、引用、可读性、正文长度、耗时、模型调用与 token、素材处理调用。没有遥测写「未测」。分别登记机器检查、人工素材复核与外部核验三种结果。
6. 测试输出留在隔离目录。只有可公开的整理示例和汇总可随仓库提交。本地媒体、原始转录与正式 EverOS 条目不入库。
