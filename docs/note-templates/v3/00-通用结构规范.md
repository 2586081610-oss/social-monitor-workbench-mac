# 通用结构规范（v3）

> 适用：所有 v3 视频笔记与图文笔记。脚标语法沿用 [`../v2/00-引用标记规范.md`](../v2/00-引用标记规范.md)，本文件只规定 v3 新增的部分。
> 配套：[`00-质量评分卡.md`](00-质量评分卡.md)、[`CHANGELOG.md`](CHANGELOG.md)。

## 一、v3 要解决什么

v2 解决了「可核验说法要挂脚标」，但仍靠人读，机器无法稳定判断一篇笔记是否合格。v3 在 v2 脚标基础上补四件事：

| 问题 | v3 做法 | 位置 |
|---|---|---|
| 笔记元数据散落在正文抬头，无法批量统计 | 文件首行起写 YAML frontmatter，固定字段名与枚举值 | 本文件第四节 |
| 脚标可能堆砌，笔记被写成文献综述 | 引用密度上限 + 80/20 计量口径 | 本文件第六、七节 |
| 台账各写各的，列不一致 | 统一七列表头，字段与 frontmatter 计数对齐 | 本文件第五节 |
| 「写完了」没有客观标准 | 100 分质量评分卡，80 分通过线 | `00-质量评分卡.md` |

## 二、内容类型路由（content_kind）

`content_kind` 是唯一路由字段，决定正文主体长什么样。判定只看素材本身，不看标题措辞。

| 取值 | 中文 | 判定信号 | 正文主体形态 |
|---|---|---|---|
| `talking_head` | 口播 / 理论 / 白板 | 静态机位、低连续运动、理论词与结论句多、有板书 | 主张 → 机制 → 做法 → 边界，配画面实读 |
| `workout_demo` | 动作教学 / 器械 / 错误示范 | 动作词多、运动集中在示范段、有正误对比 | 动作定位 → 要点 → 口令 → 常见错误 → 变式 |
| `follow_along` | 跟练 / 带练 / 连续做组 | 连续运动覆盖高、组数次数密度高、有完整训练课 | 课程结构 → 逐动作（组次休息）→ 画面实读 |
| `collection_post` | 图文 / 收藏合集 | 无视频转写、以图片与短文案为主 | 条目清单 → 主题归并 → 去重与边界 |
| `vlog` | 日常 / 记录 / 无明确教学主题 | 以行程、体验、闲聊为主，无可复用主张 | 时间线 → 关键片段 → 可复用结论（可能为空） |
| `unknown` | 无法判定 | 素材缺失、转写为空、内容混杂 | 只写来源摘要 + 待确认，判定后重写 |

规则：

1. 判定不确定时先写 `unknown`，不要猜成 `talking_head`；人工复核后改判并重写主体。
2. 类型决定「必备专属表」，见下表。表格可以加列，不能少列。
3. `vlog` 允许没有外部对照，但必须在「外部对照」节写「无（本条无可核验主张）」，不得直接删节。

| content_kind | 必备专属表 |
|---|---|
| `talking_head` | 主张-依据表（主张 / 原话时间戳 / 外部核对）、落地清单表 |
| `workout_demo` | 动作要点表（要点 / 口令 / 原片时间戳）、常见错误表、变式退阶表 |
| `follow_along` | 课程结构表（环节 / 动作 / 组次 / 休息 / 时间戳）、纠错表 |
| `collection_post` | 条目清单表（编号 / 标题或首句 / 主题 / 链接 / 备注） |
| `vlog` | 时间线表（时间 / 事件 / 可复用信息） |
| `unknown` | 无，只填来源摘要 |

## 三、统一正文顺序

十一段固定，顺序不可调换。脚本按 H2 名称匹配，因此章节名必须保留固定后缀（允许加「一、」这类前缀）。

| 顺序 | 章节 | 必填 | 内容与约束 |
|---|---|---|---|
| 0 | YAML frontmatter | 是 | 文件第 1 行起，`---` 包裹，字段见第四节 |
| 1 | 标题（H1） | 是 | 不超过 18 字，中文，不带书名号，与 frontmatter `title` 一致 |
| 2 | 来源与素材摘要 | 是 | 平台、作者、链接、发布时间、时长、转写量、抽帧数、构成比例 |
| 3 | 一句话结论 | 是 | 不超过 60 字，必须是博主本人观点，不是笔记作者评价 |
| 4 | 类型专属主体 | 是 | 按 `content_kind` 展开，至少含该类型必备表 |
| 5 | 外部对照 | 是 | 约 20%，表格优先；无则写「无」并说明原因 |
| 6 | 金句 / 判断 | 是 | 金句逐字取自转写并给时间戳；图文类写「一句话判断」 |
| 7 | 待确认 | 是 | 逐条 `[待核]`；无则写「无」 |
| 8 | 证据台账 | 是 | 七列表，见第五节 |
| 9 | 参考文献 | 是 | 与台账 DOI/URL 一一对应；无外部证据写「无」 |
| 10 | 质量自评 | 是 | 评分卡表格 + 判定，格式见 `00-质量评分卡.md` |

约束：

1. 不适用的章节保留标题并写「无」，不删除章节。删除会让解析失败，也会掩盖漏写。
2. 脚标定义不单列章节，统一放在「参考文献」节末尾，用 `[^vN]:` 形式成块列出；「质量自评」放全文最后。
3. 正文中不得出现第二份 frontmatter 或重复的台账。

## 四、YAML frontmatter schema

字段名与顺序固定。缺字段视为不合格，值未知用 `null`，不要省略。

| 字段 | 类型 | 必填 | 取值与规则 | 示例 |
|---|---|---|---|---|
| `template_version` | 整数 | 是 | 固定 `3`；决定套用哪套校验 | `3` |
| `content_kind` | 枚举 | 是 | `talking_head` / `workout_demo` / `follow_along` / `collection_post` / `vlog` / `unknown` | `talking_head` |
| `work_id` | 字符串 | 是 | 本地归档 `works` 表的 work_id（如 `16590`）；同一作品换平台或补档时保持不变；不是平台 ID | `"16590"` |
| `platform` | 枚举 | 是 | `bilibili` / `douyin` / `xiaohongshu` / `x` / `youtube` / `other` | `bilibili` |
| `external_id` | 字符串 | 是 | 平台原始 ID（BV 号、aweme_id、note id 等）；拿不到写 `unknown` | `BV1w53J6REfW` |
| `title` | 字符串 | 是 | 与 H1 完全一致，不含书名号 | `睡眠提升：先把起床时间固定` |
| `source_url` | 字符串 | 是 | 原始链接；链接失效也保留原值，另在待确认标注 | `https://www.bilibili.com/video/BVxxxxxxxxxx` |
| `published_at` | 字符串或 `null` | 是 | ISO 8601 且带时区；时间未知填 `null`，并在待确认写明未知 | `2026-01-01T12:00:00+08:00` |
| `duration_seconds` | 整数或 `null` | 是 | 原片总时长（秒）；图文类填 `null` | `754` |
| `transcript_segments` | 整数 | 是 | 转写分段数；无转写填 `0` | `186` |
| `transcript_chars` | 整数 | 是 | 转写中文字符数（不含标点、时间戳）；无转写填 `0` | `3120` |
| `frame_count` | 整数 | 是 | 实际读取并写入笔记的抽帧 / 图片数 | `12` |
| `evidence_support` | 整数 | 是 | 台账中 `s` 类型行数，没有写 `0` | `3` |
| `evidence_question` | 整数 | 是 | 台账中 `q` 类型行数，没有写 `0` | `2` |
| `evidence_data` | 整数 | 是 | 台账中 `d` 类型行数，没有写 `0` | `1` |
| `evidence_unfound` | 整数 | 是 | 台账中 `u` 类型行数，没有写 `0` | `2` |
| `evidence_strength` | 枚举 | 是 | `强` / `中` / `弱` / `冲突`；有冲突填 `冲突`，否则取台账中最弱一条外部证据 | `中` |
| `quality_score` | 整数或 `null` | 是 | 0–100，等于质量自评表合计；未自评填 `null`，发布前必须回填整数 | `88` |

字段细则：

1. `work_id` 与 `external_id` 不是一回事：前者是本地 `works` 表主键（如 `16590`），后者是平台 ID（如 BV 号）。换平台或补档时 `work_id` 保持不变。
2. `transcript_chars` 只记录素材体量，**不作为引用密度的分母**；密度分母是笔记正文字数，见第六节。
3. `evidence_*` 四个计数必须与台账行数一致，脚本会比对；不一致按脚标规范问题扣分。
4. 字符串一律加双引号，避免标题里的冒号、问号破坏 YAML。
5. 时间一律存北京时间偏移 `+08:00`，不写 `Z` 以外的其他时区，除非原平台明确给出别的时区。

填写示例：

```yaml
---
template_version: 3
content_kind: talking_head
work_id: "16590"
platform: bilibili
external_id: "BVxxxxxxxxxx"
title: "睡眠提升：先把起床时间固定"
source_url: "https://www.bilibili.com/video/BVxxxxxxxxxx"
published_at: "2026-01-01T12:00:00+08:00"
duration_seconds: 754
transcript_segments: 186
transcript_chars: 3120
frame_count: 12
evidence_support: 3
evidence_question: 2
evidence_data: 1
evidence_unfound: 2
evidence_strength: 强
quality_score: 88
---
```

## 五、统一证据台账

表头固定七列，顺序不可改：

| 编号 | 类型 | 来源 | 年份 | 支持/质疑的对象 | 强度 | DOI/URL |
|---|---|---|---|---|---|---|

示例：

| 编号 | 类型 | 来源 | 年份 | 支持/质疑的对象 | 强度 | DOI/URL |
|---|---|---|---|---|---|---|
| v1 | 原片 | BVxxxxxxxxxx 02:46–03:07 | — | 「推一组胸等于一组胸加半组三头」 | — | 原片链接 |
| s1 | 元分析 | Laborde 等 | 2022 | 慢呼吸提高 HRV | 强 | 10.1016/j.neubiorev.2022.104711 |
| q1 | RCT | 作者 | 2021 | 4-7-8 固定比例无额外收益 | 中 | 10.xxxx/xxxxx |
| d1 | 官方统计 | 机构名 | 2024 | 成年人平均睡眠时长 | 强 | https:// |
| u1 | 未找到 | — | — | 0.5 组折算系数 | — | — |

规则：

1. 台账一行对应一个唯一编号，行数等于 `evidence_support + evidence_question + evidence_data + evidence_unfound + v 类编号数`。
2. `v` 类（原片）也要进台账，`年份`、`强度`、`DOI/URL` 按示例填 `—`；`DOI/URL` 填原片链接或 `—`。
3. 只有 `u` 类允许没有外部链接；`s`/`q`/`d` 任一行缺 DOI 或可检索 URL 即不合格。
4. 强度逐行填写，取值为 `强` / `中` / `弱` / `冲突`；`u` 类和 `v` 类写 `—`。
5. 同一来源多次引用只占一行，正文可多次出现同一编号。
6. 台账与参考文献必须一致：台账里出现的每条外部来源，参考文献都要有完整条目。

## 六、引用密度

| 指标 | 规则 | 说明 |
|---|---|---|
| 整体密度 | 每 100 个中文字符 0.8–1.5 个脚标 | 低于 0.8 多半漏挂数字/机制；高于 1.5 是堆砌 |
| 单句上限 | 2 个 | 句子以 `。！？` 结尾划分 |
| 单段上限 | 4 个 | 段落以空行划分 |
| 统计口径 | 按正文**出现次数**计 | 同一编号复用也计数；不是按台账唯一编号数 |

分母 = 该笔记 H1 之后到「证据台账」之前的正文中文字符数，含表格内文字，不含 frontmatter、脚标定义、参考文献条目、纯时间戳与 DOI。表格内的脚标同样计入出现次数。

参考区间：

| 正文字数 | 建议脚标出现次数 |
|---|---|
| 500 | 4–8 |
| 1000 | 8–15 |
| 2000 | 16–30 |
| 3000 | 24–45 |
| 5000 | 40–75 |

超限处理：

1. 同一句挂三个以上：合并为一条证据，或把次要证据移到外部对照节。
2. 整段脚标过密：说明这段写成了文献综述，回删论述、只留结论句。
3. 低于下限：逐条检查数字（组数、次数、角度、分钟、比例）、机制、效果、权威结论是否漏挂。
4. 不许为了凑密度给转场句、主观评价挂脚标；无意义脚标按脚标规范扣分。

## 七、80/20 比例

| 板块 | 目标 | 计量方式 |
|---|---|---|
| 博主原片 / 口播 | 约 80%（70%–85%） | 由 `[^vN]` 支撑的段落字数 / 正文总字数 |
| 外部证据 | 约 20%（15%–25%） | 外部对照节 + 行内核对句的字数 / 正文总字数 |
| 外部上限 | 25% | 超过即视为跑偏，须回删或移出主线 |

规则：

1. 脚标是标注工具，不是内容来源。加脚标不能把笔记变成文献综述。
2. 外部对照节不超过正文的四分之一；连续 150 字以上的纯文献综述只允许出现在该节内。
3. 外部证据只核关键结论，不逐句核对；一条主张最多一条支持 + 一条质疑。
4. 计算比例时按字数，不按脚标个数；脚标多不等于外部内容多。

## 八、证据强度定义

| 强度 | 判定标准 | 典型来源 |
|---|---|---|
| 强 | 结论稳定、可重复 | 系统综述、元分析、大样本 RCT、官方指南、多个高质量研究同向 |
| 中 | 有直接研究但不够稳 | 单项 RCT、队列研究、权威机构建议、样本有限的研究 |
| 弱 | 只有间接或经验支持 | 专家意见、教练经验、机制推测、媒体转述、单一小样本 |
| 冲突 | 高质量研究结论相反 | 至少两篇同级研究结论对立，需两方都列 |

规则：

1. 没有把握就写「弱」，不得抬高中等证据。
2. 标「冲突」时正文必须写出两方结论与出处，不能只写「有争议」。
3. `evidence_strength`（frontmatter）取全篇最弱一档；只要存在冲突，直接填「冲突」。
4. 强度描述证据本身，不描述博主可信度。

## 九、版本兼容

1. v1、v2 目录不覆盖、不改写；v3 是新增目录，旧文件保持原样可复现。
2. 旧笔记仍按旧模板复现，不强制升级；升级时新建 v3 文件，保留原文件。
3. 校验以 `template_version` 为准：无 frontmatter 视为 v1/v2，不跑 v3 校验；`template_version: 3` 才校验 frontmatter、密度、评分卡。
4. v2 的脚标类型与写法（`[^vN]` / `[^sN]` / `[^qN]` / `[^dN]` / `[^uN]`）在 v3 完全沿用，不新增标记。
5. v2 的证据台账五列表在 v3 统一为七列（补 `DOI/URL`、`来源` 写全）；旧笔记不回溯改表。

## 十、可直接复制的 frontmatter 模板

```yaml
---
# 元数据（必填，勿删字段）
template_version: 3
content_kind: unknown            # talking_head | workout_demo | follow_along | collection_post | vlog | unknown
work_id: "16590"
platform: other                  # bilibili | douyin | xiaohongshu | x | youtube | other
external_id: "平台原始ID"
title: "标题（与 H1 一致，不含书名号）"
source_url: "https://"
published_at: null               # ISO 8601 带时区，如 2026-01-01T12:00:00+08:00；未知填 null
duration_seconds: null           # 图文类填 null
transcript_segments: 0
transcript_chars: 0
frame_count: 0
# 证据计数（与台账同类型行数一致，没有写 0）
evidence_support: 0
evidence_question: 0
evidence_data: 0
evidence_unfound: 0
evidence_strength: 弱            # 强 | 中 | 弱 | 冲突
# 质量
quality_score: null              # 自评后回填 0-100；发布前必须为整数
---
```

## 十一、发稿前校验

- [ ] frontmatter 从文件第 1 行开始，YAML 可解析，18 个字段齐全
- [ ] `content_kind` 在枚举内，且与正文主体形态、必备专属表一致
- [ ] 十一段顺序正确，缺失章节用「无」占位而非删除
- [ ] 台账七列表头一致，行数与 `evidence_*` 计数一致
- [ ] 外部来源都有可检索 DOI/URL，未找到的只有 `u` 类
- [ ] 引用密度在 0.8–1.5，单句不超过 2 个，单段不超过 4 个
- [ ] 外部证据占正文 15%–25%，未写成文献综述
- [ ] 至少一条质疑或未找到；只列支持视为不合格
- [ ] 质量自评表已填，`quality_score` 已回填且 ≥ 80
