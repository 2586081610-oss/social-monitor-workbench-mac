# 80/20 笔记模板 · 跟练类（v3）

> 适用：带练、跟练、连续做组、从热身到收尾的完整训练课。
> v3 新增：① 文件头 YAML frontmatter，归档与筛选可直接读结构；② 开篇「训练参数表」把动作/组数/次数/休息/替补/时间戳一次列全，未给的一律 `[待核]`；③「来源与素材摘要」交代转写段数/字数/口播密度、实读帧数与证据分布；④ 证据台账增加 DOI/URL 列；⑤ 文末 100 分制「质量自评」，80 分通过。
> 脚标规范：`../v2/00-引用标记规范.md`。v3 沿用 v2 的五类脚标，不新增类型。
> 编号说明：下文的 `[^vN]`/`[^sN]`/`[^qN]`/`[^dN]`/`[^uN]` 全是占位。复制后按正文实际出现顺序重新编号，同一来源复用同一编号，并在文末补齐定义。
> 比例硬约束：原片口播与带练示范约 80%，外部证据约 20%；外部内容集中在「外部对照」一节。
> 使用顺序：先复制下面的 YAML 块放到笔记首行，再复制正文块；两块的证据条数与质量总分必须一致。
> 本类常见扣分点：按常规方案推算组数/次数/休息；参数表与分节序号对不上；把热身动作算进正式动作；单帧当成整段行程。

```yaml
---
template_version: 3                       # 固定整数 3，决定跑哪套校验
content_kind: follow_along                # talking_head | workout_demo | follow_along | collection_post | vlog | unknown
work_id: "16590"                           # 本地 works 表 work_id，不是平台 ID
platform: douyin                          # bilibili | douyin | xiaohongshu | x | youtube | other
external_id: "7582048702325181745"        # 平台原始 ID，拿不到写 unknown
title: "标题（与 H1 一致，不含书名号）"
source_url: "https://www.douyin.com/video/xxxxxxxxxx"
published_at: null                        # ISO 8601 带时区；未知填 null，不填抓取时间
duration_seconds: null                    # 秒；未知填 null
transcript_segments: 0                    # 转写分段数，无转写填 0
transcript_chars: 0                       # 中文字符数（不含标点），无转写填 0
frame_count: 0                            # 实际读取并写入笔记的帧数
evidence_support: 0                       # 与台账 s 行数一致
evidence_question: 0                      # 与台账 q 行数一致
evidence_data: 0                          # 与台账 d 行数一致
evidence_unfound: 0                       # 与台账 u 行数一致
evidence_strength: 弱                      # 强 | 中 | 弱 | 冲突；取最弱一档，有冲突填冲突
quality_score: null                       # 0–100，等于文末自评合计
---
```
