# 模板体系变更记录

> 只记录结构调整与新增规则；日期为模板落库日期。

## v3 — 2026-11-18

- 新增 YAML frontmatter：机器可读元数据（作品 ID、平台、时间、素材体量）与证据计数（支持 / 质疑 / 权威数据 / 未找到），并记录整体证据强度与质量分。
- 新增内容类型路由：以 `content_kind` 六类枚举（`talking_head` / `workout_demo` / `follow_along` / `collection_post` / `vlog` / `unknown`）决定正文主体形态；规则见 `00-内容类型判定与路由.md`，脚本为 `tools/classify_content.py`。
- 新增每类内容专属表：按 `content_kind` 指定必备表格，禁止用同一套表覆盖所有类型；新增 `05-vlog类.md`。
- 新增统一正文顺序：frontmatter → 来源与素材摘要 → 一句话结论 → 类型专属主体 → 外部对照 → 金句/判断 → 待确认 → 证据台账 → 参考文献 → 质量自评。
- 新增脚标校验脚本 `tools/check_footnotes.py`：校验编号唯一性、正文编号与定义对应、台账行数与 frontmatter 计数一致、支持/质疑平衡、引用密度。
- 新增质量评分卡：100 分制六维度，通过线 80 分，另设五条红线；见 `00-质量评分卡.md`。
- 明确引用密度：建议每 100 字 0.8–1.5 个脚标，单句最多 2 个、单段最多 4 个；脚本硬边界为 0.2–2.0。
- 证据台账统一为七列（增 `来源` 全称与 `DOI/URL`）。

## v2 — 2026-11-17

- 新增支持 / 质疑 / 权威数据 / 未找到四类脚标，与原片脚标并列。
- 新增文末「证据台账」表，逐条列出编号、类型、来源、年份、支持或质疑的对象、强度。
- 新增硬规则：支持与质疑都要列，只列支持视为不合格；查不到写「未找到直接研究」，不得用媒体文章冒充论文。
- 四类模板（口播理论、动作教学、跟练、图文收藏）在 v1 结构上补充脚标与台账。

## v1 — 2026-11-04/05

- 建立 80/20 三套结构（口播理论、动作教学、跟练）与图文收藏结构。
- 只记录博主原话、动作、画面与数字，不挂外部证据脚标。
- 保留为历史原样，后续版本不覆盖。

## 兼容说明

- v1、v2 不覆盖、不改写；v3 为新增目录。
- 旧笔记仍可按旧模板复现；升级 v3 时新建文件，保留原文件。
- v3 完全沿用 v2 的脚标类型与写法，只增加 frontmatter、结构、密度、台账与评分要求。
