# 80/20 笔记模板 · 图文/收藏类（v3）

> 适用：X / 小红书图文、抖音收藏合集、无视频转写的条目清单、工具与资源清单。
> v3 新增：① 文件头 YAML frontmatter，归档与筛选可直接读结构；② 开设「来源与素材摘要」，无转写时明确写 N/A，改为条目数与图片实读数；③ 主体固定为「条目清单 → 主题归并 → 去重与边界 → 来源可信度分级 → 外部核查」，每条原帖信息挂原帖脚标；④ 证据台账增加 DOI/URL 列；⑤ 文末 100 分制「质量自评」，80 分通过。
> 脚标规范：`../v2/00-引用标记规范.md`。v3 沿用 v2 的五类脚标，不新增类型。
> 编号说明：下文的 `[^vN]`/`[^sN]`/`[^qN]`/`[^dN]`/`[^uN]` 全是占位。复制后按正文实际出现顺序重新编号，同一来源复用同一编号，并在文末补齐定义。
> 比例硬约束：原帖信息归并约 80%，外部核查约 20%；外部内容集中在「外部核查」一节。
> 使用顺序：先复制下面的 YAML 块放到笔记首行，再复制正文块；两块的证据条数与质量总分必须一致。
> 本类常见扣分点：条目数含未读或无关条目；把 C 级转述当 A 级原文；主题归并回指不到条目编号；逐句核查功能描述导致外部内容超 20%。

```yaml
published_at: null                        # ISO 8601 带时区；未知填 null，不填抓取时间
duration_seconds: null                    # 无视频填 null
transcript_segments: 0                    # 无转写填 0，正文摘要写 N/A
transcript_chars: 0                       # 无转写填 0，正文摘要写 N/A
frame_count: 0                            # 实读图片张数，不是保存张数
evidence_support: 0                       # 与台账 s 行数一致
evidence_question: 0                      # 与台账 q 行数一致
evidence_data: 0                          # 与台账 d 行数一致
evidence_unfound: 0                       # 与台账 u 行数一致
evidence_strength: 弱                      # 强 | 中 | 弱 | 冲突；取最弱一档，有冲突填冲突
quality_score: null                       # 0–100，等于文末自评合计
---
```

```markdown
## 三、去重与边界

| 类型 | 条目 | 处理 |
|---|---|---|
| 与已有笔记重复 |  | 只留链接，不重复写要点 |
| 搬运 / 二次转载 |  | 回查原始出处后再用 |

| 与本主题无关的凑数条目 |  | 移出，不计入条目数 |

- 去重判断只依据正文、图片与发布时间，不依据标题相似度。

## 四、来源可信度分级

| 等级 | 定义 | 判定依据 | 处理方式 |
|---|---|---|---|
| A 原始来源 | 官方文档、作者本人、机构原文 | 有原文链接且能打开 | 可直接引用[^v11] |
| B 权威媒体 | 有署名与编辑流程的主流媒体 | 署名 + 可回溯 | 引用时注明媒体 |
| C 二手转述 | 复述他人结论，无原始链接 | 无原文出处 | 必须回查原始来源[^v12] |
| D 未核实 | 作者、日期或原文都无法定位 | 截图 / 口述 / 拼图 | 不入结论 |
```
