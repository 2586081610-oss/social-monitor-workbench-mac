# 引用与证据核验 v3

| 脚标 | 作用 | 定义的最低信息 |
|---|---|---|
| `[^v1]` | 原片或原帖 | 时间或图片序号、语音/画面/OCR/配文渠道、实际确认内容 |
| `[^s1]` | 独立支持 | 作者、年份、标题、期刊/机构、DOI 或实际打开的 URL、支持范围 |
| `[^q1]` | 限制、部分支持或冲突 | 同上，并说明适用边界、人口或干预差异 |
| `[^d1]` | 权威指南、标准或数据 | 机构、版本或年份、标题、可查 URL、适用范围 |
| `[^u1]` | 已检索但未找到直接证据 | 问题、检索词和平台、日期、检索范围与限制 |

编号按各类首次出现的顺序分配，同一来源及同一定位复用编号，一条定义对应一个 JSON evidence.id。重要数字、动作、机制、效果与风险结论就近挂脚标。结尾写证据台账与定义，并区分原片核对和外部判断。

- **V0 原片事实核对**。所有正式笔记都需要。source_confirmed 仅代表素材确实有对应内容。口播与画面有冲突时分别引用，并标待核。
- **V1 重点科学核验**。核验重要机制、效果、训练容量与频率。核对结论、样本、对照、负荷和适用人群。
- **V2 深度核验**。用于争议、损伤风险、特殊人群、营养剂量；优先直接原始研究和可追溯指南，必要时比较多项研究。结论强度考虑直接性、设计、样本、偏倚、一致性与外推范围。
- 未检索或服务失败记录 not_checked 或 partial 及原因。完成有记录的检索才可用 u；支持、部分支持、冲突和证据不足按主张分别写。找不到外部研究时保留由原片确认的内容。
- 只列实际打开并能支持相应结论的研究，不凭标题或研究类别背书。作者自引、训练经验、模型推断和外部证据分别呈现。
