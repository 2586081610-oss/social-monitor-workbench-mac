# 80/20 笔记模板 · 动作教学类（v3）

> 适用：单动作讲解、器械使用、错误示范、变式与退阶等「一个动作讲透」的视频。
> v3 新增：① 文件头 YAML frontmatter，归档与筛选可直接读结构；②「来源与素材摘要」交代转写段数/字数/口播密度、实读帧数与证据分布；③ 主体固定为「动作定位 → 握法/站位/关节角度表 → 动作分解表 → 口令清单 → 常见错误 → 变式与退阶」，每个技术要点必须挂原片时间戳脚标；④ 证据台账增加 DOI/URL 列；⑤ 文末 100 分制「质量自评」，80 分通过。
> 脚标规范：`../v2/00-引用标记规范.md`。v3 沿用 v2 的五类脚标，不新增类型。
> 编号说明：下文的 `[^vN]`/`[^sN]`/`[^qN]`/`[^dN]`/`[^uN]` 全是占位。复制后按正文实际出现顺序重新编号，同一来源复用同一编号，并在文末补齐定义。
> 比例硬约束：原片口播与动作演示约 80%，外部证据约 20%；外部内容集中在「外部对照」一节。
> 使用顺序：先复制下面的 YAML 块放到笔记首行，再复制正文块；两块的证据条数与质量总分必须一致。
> 本类常见扣分点：技术要点没有时间戳；图注写了单帧看不出的行程；口令被润色成教科书术语；站距/脚尖等侧机位看不见的项没标 `[待核]`。
