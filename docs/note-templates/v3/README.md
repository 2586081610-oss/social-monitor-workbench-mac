## 三、快速开始

### 1. 判断内容类型

```bash
python3 docs/note-templates/v3/tools/classify_content.py --input features.json
```

低置信时输出 `unknown` 或 `needs_llm=true`，不要硬判。特征字段见 `00-内容类型判定与路由.md` 第六节。

### 2. 选模板

| content_kind | 模板 | 必备专属表 |
|---|---|---|
| `talking_head` | `01-口播理论类.md` | 概念定义、机制链、反例与边界 |
| `workout_demo` | `02-动作教学类.md` | 握法/角度表、动作分解表、常见错误、变式退阶 |
| `follow_along` | `03-跟练类.md` | 训练参数表（组数/次数/休息）、纠错表 |
| `collection_post` | `04-图文收藏类.md` | 条目清单、来源可信度分级、去重边界 |
| `vlog` | `05-vlog类.md` | 时间线、关键信息、可复用信息 |
| `unknown` | 不产出 | 先补特征或交人工复核 |

### 3. 写笔记

- 复制模板里的 YAML frontmatter 和正文块。
- 模板里的 `[^vN]` 等编号是占位，按正文实际出现顺序重新编号，并在文末补齐定义。
- 保持约 80% 原片/博主 + 20% 外部证据。
- 每个数字、机制、效果判断都要挂脚标；支持与质疑都要列。
- 查不到就写 `[^uN]: 未找到直接研究`，不得编造文献。

### 4. 跑脚标校验

```bash
python3 docs/note-templates/v3/tools/check_footnotes.py <note.md>
python3 docs/note-templates/v3/tools/check_footnotes.py <note.md> --strict
python3 docs/note-templates/v3/tools/check_footnotes.py <note.md> --json
```

- 有 error 退出码 1；`--strict` 下 warning 也退出 1。
- 模板本身是空壳，校验对象是**写完的笔记**；模板里的脚标在代码块中，不会被当成引用。

### 5. 自评

按 `00-质量评分卡.md` 在文末填「质量自评」表。低于 80 分不得标记完成。

## 五、硬规则

1. 数字必须来自转写原文或画面，不得把自己的推算写成“他说”。
2. 同音错必须列，不能照抄错名。
3. 文献不得编造；查不到就写「未找到直接研究」。
4. 不确定标 `[待核]`。
5. 画面实读只写实际看到的，图注不能按口播想象。
6. 支持与质疑都要列，只列支持视为不合格。
7. 外部证据约占 20%，脚标不能把笔记变成文献综述。
8. 不适用的章节保留标题写「无」，不要删除，便于脚本稳定匹配。
